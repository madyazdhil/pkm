# Download Dataset Excel Peserta

Bapak/Ibu peserta dapat mengunduh salah satu file latihan berikut sesuai kelompoknya.

Semua file berisi **100 data sintetis** dan memiliki dua sheet:

- `Data` — data latihan yang dipakai untuk membuat dashboard.
- `Panduan` — penjelasan arti kolom dan catatan penggunaan.

> Gunakan file latihan ini selama workshop. Jangan mengganti dengan NIK, nomor KK, nomor telepon, alamat lengkap, isi surat, atau data warga asli.

## File Excel per kelompok

### Kelompok 1 — Rekap Layanan Kecamatan

Cocok untuk latihan KPI total layanan, status selesai/diproses/dibatalkan, jenis layanan, dan unit penanggung jawab.

- [Download Excel — dummy-data-rekap-layanan-kecamatan.xlsx](https://github.com/madyazdhil/pkm/raw/main/outputs/2026-10-04-workshop-bundle/03-datasets/dummy-data-rekap-layanan-kecamatan.xlsx)

### Kelompok 2 — Monitoring Surat dan Disposisi

Cocok untuk latihan status surat, prioritas, tenggat, unit tujuan, dan monitoring tindak lanjut.

- [Download Excel — dummy-data-monitoring-surat-disposisi.xlsx](https://github.com/madyazdhil/pkm/raw/main/outputs/2026-10-04-workshop-bundle/03-datasets/dummy-data-monitoring-surat-disposisi.xlsx)

### Kelompok 3 — Agenda Kegiatan Internal

Cocok untuk latihan status persiapan, tanggal kegiatan, lokasi umum, unit pelaksana, dan agenda mendatang.

- [Download Excel — dummy-data-agenda-kegiatan-internal.xlsx](https://github.com/madyazdhil/pkm/raw/main/outputs/2026-10-04-workshop-bundle/03-datasets/dummy-data-agenda-kegiatan-internal.xlsx)

## Setelah file diunduh

1. Buka file Excel sesuai kelompok.
2. Periksa sheet `Panduan` untuk memahami kolom.
3. Periksa sheet `Data` dan jangan mengubah nama header.
4. Unggah atau impor file ke Google Sheets.
5. Gunakan Google Sheets sebagai sumber data dashboard.
6. Ikuti [panduan import dan deployment](participant-import-and-deploy-guide.md) jika perlu.
