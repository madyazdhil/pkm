# Checklist Peserta: Data sampai Dashboard Link

## Sebelum mulai

- [ ] Saya memakai file latihan atau data yang sudah diizinkan dan dianonimkan.
- [ ] Tidak ada NIK, nomor KK, nomor telepon, alamat lengkap, isi surat, isi aduan, password, token, atau API key.
- [ ] Saya tahu siapa yang akan membaca dashboard.
- [ ] Saya tahu pertanyaan kerja yang ingin dijawab.

## Impor Excel

- [ ] File Excel sudah diunggah ke Google Drive.
- [ ] File sudah dibuka atau dikonversi menjadi Google Sheets.
- [ ] Sheet sumber bernama `Data`.
- [ ] Header tidak berubah.
- [ ] Tanggal terbaca sebagai tanggal.
- [ ] Status konsisten.
- [ ] Dataset latihan terbaca 100 baris.

## Dashboard minimum

- [ ] Kartu Total Layanan tampil.
- [ ] Kartu Selesai tampil.
- [ ] Kartu Masih Diproses tampil.
- [ ] Tabel tampil dan mudah dibaca.
- [ ] Filter status bekerja.
- [ ] Filter jenis layanan bekerja.
- [ ] Grafik jenis layanan tampil.
- [ ] Tanggal pembaruan tampil.
- [ ] Label data latihan/sintetis tampil.

## Verifikasi

- [ ] Saya membandingkan KPI dengan hitungan manual di Sheet.
- [ ] Saya mengubah satu baris data dan memeriksa apakah angka ikut berubah.
- [ ] Saya mencoba filter dan memeriksa jumlah baris.
- [ ] Saya membaca pesan error secara lengkap jika ada.
- [ ] Saya mencatat perubahan yang dibuat.

## Link dan akses

- [ ] Saya memiliki URL/link hasil deployment atau screenshot fallback.
- [ ] Saya menguji link dengan akun yang berhak mengakses.
- [ ] Saya tidak menyebut deployment berhasil sebelum link benar-benar terbuka.
- [ ] Saya tahu siapa PIC yang menyimpan dan memperbarui data.
